# Werkregels

- Antwoord altijd in eenvoudig Nederlands.
- Ik ben een beginnende programmeur op Windows met PowerShell.
- Pas nooit een bestand aan zonder eerst te laten zien wat je gaat wijzigen en wacht op mijn goedkeuring.
- Vervang nooit een compleet bestand, alleen kleine gerichte wijzigingen.
- Verwijder of herschrijf nooit werkende code.
- Gebruik geen nieuwe frameworks of libraries.
- Doe één kleine stap tegelijk.
- Gebruik `npm.cmd` en `firebase.cmd` in terminalcommando's.
- Maak nooit zelf een git commit of push, dat doe ik.
